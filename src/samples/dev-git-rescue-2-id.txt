[cover kicker="GIT RESCUE • #2"]
Commit ke Branch | yang Salah?
Belum di-push? Pindahin tanpa kehilangan apa-apa. Simpan buat pas panik.
---
[code]
Branch tujuannya belum ada
Bikin branch di posisi commit itu, lalu mundurkan main satu commit.
```bash
git branch fitur-login
git reset --hard HEAD~1
git switch fitur-login
```
Commit-nya sekarang di fitur-login, main bersih lagi.
---
[code]
Branch tujuannya sudah ada
Salin commit-nya ke sana, lalu hapus dari main.
```bash
git switch fitur-login
git cherry-pick main
git switch main
git reset --hard HEAD~1
```
cherry-pick main menyalin commit terakhir di main.
---
[card]
Hati-hati dengan `reset --hard`
Perubahan yang belum di-commit ikut hilang. Cek `git status` dulu, dan simpan pakai `git stash` kalau perlu.
---
[card]
Sudah telanjur di-push?
Jangan reset branch yang dipakai bareng. Salin dulu ke branch yang benar pakai `cherry-pick`, lalu `git revert` commit itu di main.
---
[code number=off]
Simpan ini
Pilih sesuai kondisimu. Cek `git status` dulu.
```bash
# kalau branch tujuan belum ada
git branch fitur-login
git reset --hard HEAD~1
git switch fitur-login
# kalau branch tujuan sudah ada
git switch fitur-login
git cherry-pick main
git switch main
git reset --hard HEAD~1
```
