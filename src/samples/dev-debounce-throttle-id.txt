Ketik "laptop", | Server Dapat 6 Request
Debounce bikin jadi 1. Ini beda debounce dan throttle, plus kapan pakai yang mana.
---
[code]
Masalahnya
Setiap huruf memicu event input, dan setiap event memanggil `search()`.
```js
input.oninput = (e) => {
  search(e.target.value);
};
```
---
Debounce: tunggu sampai berhenti
Fungsi baru jalan setelah tidak ada event selama sekian ms. Setiap event baru mengulang hitungannya dari nol.
---
[code]
Debounce dalam 7 baris
Setiap panggilan membatalkan timer sebelumnya.
```js
function debounce(fn, ms) {
  let id;
  return (...args) => {
    clearTimeout(id);
    id = setTimeout(fn, ms, ...args);
  };
}
```
---
[code]
Pasang di search input
Ketik "laptop" tanpa jeda, `search()` cuma jalan sekali: 300 ms setelah huruf terakhir.
```js
const cari = debounce(search, 300);
input.oninput = (e) => {
  cari(e.target.value);
};
```
---
Throttle: paling sering sekali per interval
Event tetap datang terus, tapi fungsi dipanggil maksimal sekali tiap sekian ms. Cocok untuk event yang jalan terus seperti scroll.
---
[code]
Throttle sederhana
Panggilan yang terlalu cepat diabaikan.
```js
function throttle(fn, ms) {
  let last = 0;
  return (...args) => {
    const now = Date.now();
    if (now - last < ms) return;
    last = now;
    fn(...args);
  };
}
```
Pakai: `throttle(onScroll, 200)` di event scroll.
---
Kapan pakai yang mana?
Butuh hasil akhir saja: debounce (search, validasi form). Butuh update rutin selama event jalan: throttle (scroll, mousemove). Lodash juga punya keduanya siap pakai.
