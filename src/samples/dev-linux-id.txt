Port 3000 | Udah Dipakai?
Cek pakai lsof, plus 6 perintah lain yang sering kepakai. Simpan buat pas butuh.
---
[code]
Cari proses yang pakai port
Berguna pas muncul “port already in use”.
```bash
lsof -i :3000
```
---
[code]
Lihat isi folder, lengkap
Termasuk file tersembunyi dan ukurannya.
```bash
ls -lah
```
---
[code]
Cari teks di banyak file
Rekursif, lengkap dengan nomor baris.
```bash
grep -rn "TODO" src/
```
---
[code]
Pantau log secara langsung
Baris baru muncul otomatis.
```bash
tail -f app.log
```
Tekan Ctrl+C untuk berhenti.
---
[code]
Cek folder yang paling besar
Urutkan ukuran dari yang terbesar.
```bash
du -sh * | sort -rh
```
---
[code]
Bikin script bisa dijalankan
Tambahkan izin eksekusi, lalu jalankan.
```bash
chmod +x deploy.sh
./deploy.sh
```
---
[code]
Ulangi perintah terakhir pakai sudo
Nggak perlu ngetik ulang dari awal.
```bash
sudo !!
```
Pastikan kamu tahu perintah apa yang diulang.
---
[code number=off]
Simpan ini
Cari kebutuhanmu, jalankan baris di bawahnya.
```bash
# siapa pakai port 3000?
lsof -i :3000
# isi folder, lengkap
ls -lah
# cari teks di file
grep -rn "TODO" src/
# pantau log
tail -f app.log
# folder paling besar
du -sh * | sort -rh
# bikin script jalan
chmod +x deploy.sh
# ulangi pakai sudo
sudo !!
```
