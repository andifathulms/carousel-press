Soal 1: output-nya apa?
A. 2
B. 3
C. 2.5
```py
print(round(2.5))
```
---
[code number=off]
Jawaban: A
Kalau pas di tengah, round() memilih angka genap terdekat.
```py
print(round(2.5))
# 2
print(round(3.5))
# 4
```
Namanya banker's rounding, biar pembulatan nggak condong ke atas.

[code number=off]

```py
# True
print(bool(""))

```

Soal 3: output-nya apa?
A. [1, 2]
B. [1, 2, 3]
C. error
```py
a = [1, 2]
b = a
b.append(3)
print(a)
```
---
[code number=off]
Jawaban: B
`b = a` nggak bikin salinan. a dan b nunjuk ke list yang sama.
```py
a = [1, 2]
b = a
b.append(3)
print(a)
# [1, 2, 3]
```
Mau salinan? Pakai `b = a.copy()`, hasilnya [1, 2].
