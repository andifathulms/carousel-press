AI Bisa Salah | dengan Sangat Yakin
5 cara aku pakai AI buat coding, termasuk cara ngecek hasilnya.
---
[code]
Minta jelasin error, bukan cuma fix
Kamu jadi paham, bukan sekadar copy paste.
```
Jelasin kenapa error ini muncul,
lalu kasih 2 cara memperbaikinya:
TypeError: Cannot read properties
of undefined (reading 'map')
```
---
[code]
Kasih konteks yang cukup
Sebutin bahasa, framework, dan tujuanmu.
```
Aku pakai React + TypeScript.
Komponen ini harus nampilin daftar
user dari API. Ini kodenya: ...
```
---
[code]
Minta review sebelum push
Anggap AI teman yang teliti.
```
Review kode ini. Cari bug,
edge case, dan nama variabel
yang kurang jelas.
```
---
[code]
Pakai buat bikin test
Seringnya, ini yang paling hemat waktu.
```
Tulis unit test buat fungsi ini.
Sertakan kasus input kosong
dan input yang salah.
```
---
Tetap cek hasilnya
AI bisa salah dengan sangat yakin.
Jalankan, baca, dan pahami kodenya sebelum dipakai.
